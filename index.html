৪. ☁️ Cloudflare Workers AI (ফ্রি লাইভ জেনারেটিভ এআই সার্ভার)

⚪ যাচাই করা হচ্ছে...

Cloudflare Workers AI যুক্ত থাকলে সাইটের সকল ভিজিটর কোনো API Key ছাড়াই Llama 3.3 70B মডেলের মাধ্যমে একদম স্বাভাবিক বাংলায় লাইভ স্ট্রিমিং কথোপকথন ও শতভাগ DAWAH X দলিলভিত্তিক সুবিন্যস্ত ব্যাখ্যা পাবেন। Cloudflare-এ সাইটটি সরাসরি ওপেন করলে এটি অটোমেটিক চালু থাকে; আর GitHub Pages থেকে ব্যবহার করতে আপনার Worker URL নিচে দিন:

📘 ১ মিনিটে ফ্রি Cloudflare Workers AI চালুর নিয়ম দেখুন
  1. আপনার Cloudflare Dashboard ↗-এ লগইন করে বাম মেনু থেকে Workers & Pages → Create-এ যান।
  2. Import a repository সিলেক্ট করে GitHub থেকে আপনার dawah-x/card রিপোজিটরিটি যুক্ত করুন এবং Deploy চাপুন (এই রিপোজিটরিতে wrangler.toml ও [ai] বাইন্ডিং আগে থেকেই সম্পূর্ণ রেডি আছে)।
  3. ডিপ্লয় শেষ হলে পাওয়া https://dawahx-ai.<subdomain>.workers.dev লিংকটি সরাসরি ব্যবহার করুন অথবা উপরের বক্সে পেস্ট করে সেভ করুন!
